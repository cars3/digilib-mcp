Add Digilib to Claude in a minute

Copy this into your .mcp.json and reload your project.

// .mcp.json
{
  "mcpServers": {
    "digilib": {
      "command": "/path/to/venv/bin/python",
      "args": ["-m", "digilib_mcp.server"],
      "cwd": "/path/to/digilib-mcp"
    }
  }
}

1. Install

uv pip install -r requirements.txt

2. Configure

Add the snippet above to .mcp.json at your project root.

3. Reload

Approve the digilib server in Claude Code or Claude Desktop.
